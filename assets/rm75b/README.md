# RM75B 仿真模型

七轴机械臂 URDF 来自用户提供的 FastUMI_Data/assets/rm_75.urdf；机械臂网格来自 RealManRobot ROS 2 仓库的 rm_description/meshes/rm_75_arm，供应商仓库提交为 `08820fe5ae8c840c12d646106d27632128cde0f3`。机械臂资源的许可证见 LICENSE（Apache-2.0）。

夹爪定义和三个 STL 网格来自用户提供的 FastUMI_Data 模型，源 CAD 为 `夹爪.stp`；供应商机械臂许可证不代表夹爪资源的许可证。夹爪包含主体、底板、相机和左右夹指，移除了手持握柄。STL 使用毫米和原装配坐标，加载时缩放为米。

原始模型名称为 `rm_75_description`，未进一步区分 RM75B；本项目使用 `rm75b` 作为设备配置名。模型保留七个旋转关节，以 `Link7` 为法兰。夹爪主体相对法兰沿 +Z 偏移 6 mm 安装；该偏移用于模型装配，不能作为经过实测的抓取 TCP，TCP 应单独标定。夹爪没有实测质量和惯量，当前回放也不模拟夹爪接触动力学。

左右夹指为沿 X 的平移关节：左指沿 −X、右指沿 +X 向内运动。关节零位保留 CAD 全开姿态；按 STL 实际 X 边界，两指内侧全开间距为 36.468 mm，每指最大内移 18.134 mm，闭合后整体 X 边界仍保留约 0.2 mm 间隙。归一化开度 1 对应零位全开，0 对应最大内移，中间线性插值；`configs/robots/rm75b.yaml` 的 `gripper_max_width_m` 使用该 36.468 mm 模型间距。夹指为弯曲形状，实际指尖间隙可能大于整体边界间隙；上述数值只是碰撞安全近似，不表示实物净宽或抓取精度。

七轴机械臂接口不变，`Link7` 正运动学不受夹指位置影响。RM75B 转换数据保持既有七轴布局，不新增米制夹爪宽度列；夹爪开度作为独立的 `observation.gripper.<side>.normalized` 辅助列保存。内部回放状态为七轴加两个夹指关节，查看器直接显示开合；旧七列数据仍可加载，缺少独立开度列时夹指保持 home 的夹指姿态，有该列时 `handumi replay-joints` 会逐帧恢复双指位置。
