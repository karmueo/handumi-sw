# RM75B 仿真模型

模型来自用户提供的 FastUMI_Data/assets/rm_75.urdf，网格来自 RealManRobot ROS 2 仓库的 rm_description/meshes/rm_75_arm。供应商仓库提交：08820fe5ae8c840c12d646106d27632128cde0f3。许可证见 LICENSE（Apache-2.0）。

原始模型名称为 rm_75_description，未进一步区分 RM75B；本项目使用 rm75b 作为用户设备配置名。仅修改资源路径和添加说明。模型包含七个旋转关节，末端为 Link7；不包含夹爪或经过实测的抓取 TCP。
